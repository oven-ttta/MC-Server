# คู่มือการติดตั้ง Minecraft Server บน Ubuntu

ไฟล์เหล่านี้เตรียมไว้สำหรับนำไปรันบนเครื่อง Ubuntu Server

## วิธีการใช้งาน

1. **อัปโหลดไฟล์**
   นำไฟล์ `setup_ubuntu.sh` ไปไว้บนเครื่อง Ubuntu ของคุณ (เช่นผ่าน FTP หรือ SCP)

2. **ให้สิทธิ์การรัน**
   เปิด Terminal และพิมพ์คำสั่งให้สิทธิ์ไฟล์:
   ```bash
   chmod +x setup_ubuntu.sh
   ```

3. **เริ่มการติดตั้ง**
   รันสคริปต์ติดตั้ง:
   ```bash
   ./setup_ubuntu.sh
   ```
   *ระบบจะทำการติดตั้ง Java, ดาวน์โหลดตัวเข้าเกม (PaperMC), ติดตั้ง Geyser (สำหรับมือถือ), Floodgate, และตั้งค่าให้รองรับไอดีเถื่อนอัตโนมัติ*

4. **การเปิดเซิร์ฟเวอร์**
   หลังจากติดตั้งเสร็จ จะมีโฟลเดอร์ `minecraft_server` สร้างขึ้นมา ให้รันคำสั่ง:
   ```bash
   cd minecraft_server
   ./start.sh
   ```
   
## ข้อมูลการเข้าเล่น

- **คอมพิวเตอร์ (Java Edition)**: 
  - IP: `IP_ของเครื่อง_Ubuntu`
  - Port: `25565` (ไม่ต้องใส่ก็ได้)
  
- **มือถือ (Bedrock Edition)**:
  - IP: `IP_ของเครื่อง_Ubuntu`
  - Port: `19132` (สำคัญ)

## การปรับแต่ง

- **เพิ่ม/ลด แรม**: แก้ไขไฟล์ `minecraft_server/start.sh` ตรง `-Xmx4G` (4GB) เป็นค่าที่ต้องการ
- **การรันเบื้องหลัง**: แนะนำให้ใช้ `screen` เพื่อให้เซิร์ฟเวอร์ไม่ดับตอนปิดคอม:
  ```bash
  screen -S mc
  cd minecraft_server
  ./start.sh
  ```
  (กด `Ctrl+A` แล้ว `D` เพื่อพับหน้าจอ, พิมพ์ `screen -r mc` เพื่อกลับมาดู)
